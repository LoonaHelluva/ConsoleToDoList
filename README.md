# Console To-Do Application

Простое и надежное консольное приложение для управления задачами, написанное на C# (.NET 8).

## Особенности
* Хранение и загрузка задач из JSON-файла (`System.Text.Json`).
* Безопасная валидация ввода пользователя без падений программы.
* Полный CRUD: создание, просмотр, отмечивание и удаление задач.

## Как запустить
1. Клонируйте репозиторий: `git clone https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git`
2. Перейдите в папку с проектом.
3. Выполните команду: `dotnet run`
